# AutoCAD 插件骨架

这个目录是 AutoCAD .NET 插件的 C# 工程。核心算法放在 `SteelGrid.Core`，AutoCAD 交互放在 `SteelGrid.Plugin`。

## 结构

```text
SteelGrid.CadPlugin.sln
src/
├─ SteelGrid.Core/          # 纯算法，不依赖 AutoCAD
└─ SteelGrid.Plugin/        # AutoCAD 命令、菜单、面板（Release 产物在 bin/Release/vX/）
test/
└─ GridTest/                # 离线自检：DXF 解析 + 排条 + 边框料
docs/                       # 设计文档；docs/svg/ 为 SVG 检查图
package/
├─ PackageContents.xml             # Bundle 清单源文件
└─ SteelGrid-vX.Y.bundle/          # 各版本独立的可部署 Bundle
   ├─ PackageContents.xml
   └─ Contents/
      ├─ SteelGrid.Plugin.dll
      └─ SteelGrid.Core.dll
```

设计文档：

```text
docs/
├─ 项目进度与交接.md         # 新会话接手先读这份（进度 / 规则 / 踩坑 / 剩余任务）
├─ 矩形与梯形排条方案.md     # 多边形路径设计；§7.1 是缺口 / 缺角规则
├─ 扇形排条方案.md           # 扇形与连续折弯弧边框的实现方案
├─ 凸凹图形排条解决方案.md   # 凸出 / 凹凸混合图形的排条处理方案
├─ 待优化事项.md             # 后续优化方向与优先级
└─ svg/                      # GridTest --outline 生成的 SVG 检查图
```

## AutoCAD 版本

当前按 AutoCAD 2020 准备，目标框架为 `.NET Framework 4.8`，平台 `x64`。

## AutoCAD 引用

`SteelGrid.Plugin.csproj` 使用环境变量 `ACAD_2020_ROOT` 定位 AutoCAD 安装目录；未设置时会使用当前机器的默认路径。

引用这些 DLL：

```text
$(ACAD_2020_ROOT)\acmgd.dll
$(ACAD_2020_ROOT)\acdbmgd.dll
$(ACAD_2020_ROOT)\accoremgd.dll
```

在系统环境变量中设置，例如：

```text
ACAD_2020_ROOT=D:\CAD\AutoCAD\AutoCAD 2020
```

AutoCAD 2020 如果 API 目录相同，也可以使用这个变量。

## 当前已实现

- `BarType` 支持 `扁钢` 和 `扭绞方钢`
- 支持矩形（含凹口 / 缺角 / 凸出）、梯形 / 平行四边形，以及**带缺口 / 缺角的梯形**
- 板件、净空、缺口几何计算
- 纵横扁钢布置、截短、分段、孔位计算
- AutoCAD 命令骨架：
  - `GPGRIDSET`：打开参数面板
  - `GPGRID`：窗口框选一个或多个闭合轮廓，批量生成排条图（自动按两列排布）
  - `GPGRIDNOBORDER`：将所选轮廓直接作为排条区域，不应用缩尺或边框厚度，只生成横条 / 纵条及对应下料表
  - `GPGRIDINFO`：显示当前算法版本

- 弧形图形支持半圆缺口、扇形以及矩形圆弧缺角；圆弧边框按整根折弯料处理。

AutoCAD 专用部分需要在装有 AutoCAD 2020 的机器上编译调试。

## 离线自检

核心算法和读取层都可以不装 AutoCAD 直接验证（`test/GridTest`）：

```text
GridTest.exe --geom              # 多边形裁剪、斜边短边切平、轮廓解析自检
GridTest.exe --outline <dxf>     # 轮廓解析 + 多边形排条 + 边框料 + 下料表验收
GridTest.exe <dxf>               # 矩形（凹口 / 缺角 / 凸出）排条回归
```

`--outline` 还会为每个排条成功的图形生成 SVG 检查图（`docs/svg/图形N（宽x高）.svg`）：
绿 = 原始轮廓、红 = 外框线、灰 = 内框线、蓝 / 橙 = 边框料，料中间标下料长度。
