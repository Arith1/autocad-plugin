# 矩形与梯形排条方案

## 1. 本期范围

- 本期只支持直线边凸轮廓：矩形、梯形（含平行四边形）。
- 弧形轮廓（半圆缺口、扇形异形等）暂不支持，标记为待定；识别到弧段（`bulge != 0`）时提示“弧形暂不支持”并跳过该图形。
- `异形图.dxf` 共 5 个图形：图形 2、4、5 是梯形（图形 5 为图形 4 整体旋转 90 度）在本期范围内；图形 1（半圆缺口）、图形 3（扇形异形）暂不支持。

## 2. 现状

矩形走现有“外接矩形 − 矩形空洞”逻辑，保持不变，避免回归。
梯形新增一条多边形路径，与矩形路径并行。

## 3. 统一模型

```text
PolygonRegion {
  vertices: Point2d[]   // 局部坐标，逆时针
  bounds: Rect          // 包围盒，用于网格布置范围
}
```

- 只处理直线段，不处理弧段。
- 核心能力放 `SteelGrid.Core/Geometry/Polygon.cs`：

```text
PointInPolygon(p, poly)            // 点是否在多边形内
ClipSegmentToPolygon(seg, poly)    // 直线段被多边形裁剪
ClipBandToPolygon(center, halfW, axis, poly)  // 条带裁剪，输出 0..N 段
InsetPolygon(poly, distance)       // 凸多边形向内偏移
```

## 4. 识别（读取层）

1. 读闭合 `LWPOLYLINE` 的顶点。
2. 检查每条边的 `bulge`：非零则提示“弧形暂不支持”，跳过该图形。
3. 分类：横平竖直的四边形判为矩形（走现有矩形路径）；对边平行且等长判为平行四边形；其余凸四边形按梯形处理；后两者几何路径统一。
4. 局部坐标系：**与图纸方向一致，只平移不旋转**（原点平移到包围盒最小值）。条的方向、边框的横/竖归类都按图纸方向判断，图形整体旋转不影响它们；同时记录原点与两根轴向量，便于把生成的结果映射回世界坐标。
5. 批量时矩形和梯形混合处理，单个失败不中断，失败原因随图形一起提示。

## 5. 几何与净空

```text
板多边形 = 原始轮廓先按缩尺向内偏移得到的板件轮廓
净空多边形 = InsetPolygon(板多边形, 边框厚度)
```

- 缩尺：默认每边向内缩 5，得到钢格板外框（板件）。
- 直线边：沿内法线平移 `t`，相邻边求交得到新顶点。
- 锐角处偏移可能产生极短边，用最小边长阈值清理。

## 6. 排条

沿用现有正交网格思想，把“矩形净空 + 缺口裁剪”换成“多边形净空 + 条带裁剪”：

- 纵条：中心 x 处竖直条带 `[x-t/2, x+t/2]`，用 `ClipBandToPolygon` 与净空多边形求交，输出 0..N 段。
- 横条：中心 y 处水平条带同理。
- 满长/整长判定：段长接近净空在该方向的投影跨度时算满长。
- 孔位：纵条段 ∩ 横条段取交点，且落在净空多边形内；首孔距、尾孔距、孔数沿用现有逻辑。
- 中心距布置范围取净空多边形包围盒的投影跨度，`PlaceCenters` 不变。

### 6.1 斜边截断：按短边切平

条被斜边斜着截断时，条的两条长边落在斜边上的长度不同（示例：左侧 67、右侧 51，底边是斜边）。

- 现实不能按斜口下料，所以这条按**较短的一侧**取整：示例条就是 `5 x 51` 的矩形，长边多出来的三角（16 x 5 / 2）算废料。
- 定位：条从直角端（靠边框的一端）起按短边长度铺，保证整根矩形都落在净空多边形内，斜边一侧留空。
- 两条长边长度差 ≤ 0.5mm 时按直角处理，不触发斜边规则。
- 以纵条为例：条带两条长边 `x=x0`、`x=x1` 在净空多边形内的区间分别是 `[a0,b0]`、`[a1,b1]`，实际下料段取 `A = max(a0,a1)`、`B = min(b0,b1)`，长短边差异自动落到短边。横条同理。
- 段数据同时保留实际下料段（`A/B`）与斜边处的理论两端长度（`RawStart/RawEnd`），供图纸标注和离线自检核对。
- 下料表不单独提示斜边切平：这类条与普通条一样，只显示规格和长度；`RawStart/RawEnd` 只用于离线自检。
- 已落地：`SteelGrid.Core/Geometry/Polygon.cs` 的 `ClipBand` 按本规则返回 `BandCut`；离线自检 `GridTest --geom`。

### 6.2 端头孔距不足的处理

孔到条端的距离太近（小于**边框厚 + 该条厚/2**，5mm 条 + 5mm 边框时就是 7.5mm）时冲床打不了孔，按下面处理：

- 该交点**两根条都不打孔**（图上不画、不标注，下料表孔数各减一），最后统一清一遍"端距不足"的孔，保证任何段的孔距都 ≥ 最小孔距。
- 竖向受力时**只截断横条、不截断纵条**（纵条要继续顶到边框；两边都截会出现条碰不到边框）：
  - 若横条在这个交点的端距也不够（两根条的端头都在同一角上）→ 把横条在斜边侧断开，缩短量 = **横条自己的孔距 + 被截断纵条厚/2**，断口正好落在纵条的内侧边上（例：孔距 5.27 + 2.5 = 7.77，端头 75.28 → 83.045）。
  - 若横条还长着（离交点很远）→ 只删孔，不动条。
- 水平受力时整体对调（只截断纵条）。
- 扭绞方钢方向同样按"不生成该孔 + 端头切短"处理，现场用焊枪打掉即可。

## 7. 边框

矩形仍走现有 `FrameSplitter`；梯形走 `PolygonFrameSplitter`，每条边一根直料：

- 直线边：一根直料，长度按内外边框线取——**包边方向取外边框线长度**（板件轮廓该边长），**被包方向取内边框线长度**（净空轮廓该边长）；水平受力时对调。斜接角自动按实际长度算，不必为斜边特判，矩形/梯形/将来扇形共用一套规则。
- 斜边料是旋转矩形，角度取该边与图纸 X 轴的夹角。
- 定位：**以"取长度的那条线"为基准**——包边的料按外边框线中点定位（外长边落在板件外轮廓线上），被包的料按内边框线中点定位（内长边落在内边框线上）。两条长边分别贴住内外边框线，端头按该线自己的长度对齐，斜接角不会错位。
- 包边顺序按**图纸方向**判断：垂直受力时接近水平的边（含近水平斜边）包住接近垂直的边（含近垂直斜边），水平受力相反。
- 兜底：四条边都落在同一半区（例如图形整体旋转 45°）时，按偏离水平的角度排序，最接近水平的两个边当包边、最接近垂直的两个边当被包，保证总有两条包边。
- 斜边料本身是旋转后的直角矩形，不按 6.1 的短边规则截断；6.1 只作用于被斜边截断的横/纵条。
- 下料表不单独标记斜边料，与条一致只记规格和长度。

## 7.1 缺口（带缺口的梯形/多边形）

### 7.1.1 坐标定义（与矩形路径同一套）

缺口在**板件坐标**里定义，不是原始坐标：

```text
开口宽度 = 原始缺口宽 + 2 × 缩尺      （缩尺把图形整体内移，缺口两端各多出一个缩尺量）
缺口深度 = 原始缺口深                  （深度不变，从板件边量起）
净空缺口 = 板件缺口再外扩 1 个边框厚    （缺口四周的边框料占位）
          外扩 = 缺口的每条边沿**各自的外法线**平移后求交（斜口缺口同样适用），
          不是"沿开口方向加宽 + 沿基准边法线整体平移"（那种只在开口垂直于侧壁时成立）
```

反过来说：在原始坐标里，缺口的开口落在原始轮廓边上、深度方向要多出一个缩尺量，这样减完缩尺后深度才等于原始深度。

### 7.1.2 边框线

- **外轮廓线** = `NotchedOutline(板件多边形, 板件缺口)`：沿板件多边形逆时针走，遇到缺口开口沿缺口链绕进去再出来，是一条**带缺口的凹轮廓折线**；
- **内边框线** = `NotchedOutline(净空多边形, 净空缺口)`：同样带缺口；
- 这两条线**只用于 SVG 核对图和排查**，**实际排条图不画**（外形由边框料矩形体现）。

### 7.1.3 边框矩形（每条边一根料）

**区域先定死，再看料：**

```text
外框线 = 原始闭合轮廓（含缺角/缺口）向内偏移 缩尺
内框线 = 外框线再向内偏移 一个边框厚
排条区域 = 内框线以内
边框矩形区域 = 内外框线之间的带
```

长度规则（缺角、凹口、斜边同一套）：

- 取该边两端的两组交点：内框线交点 `a`、`b`，外框线交点 `A`、`B`；
- 沿**该边自身方向**量跨两端的四段距离：`|AB|`、`|ab|`、`|Ab|`、`|aB|`（同一端的内外两点只差一个边框厚，不算）；
- **包边方向取最大值**（垂直受力时的横边：要盖住相邻的纵边），**被包方向取最小值**（纵边让位）；水平受力时两者对调；
- 料贴在内外框线之间：包边以**外框线**为基准（外长边贴外线），被包以**内框线**为基准（内长边贴内线）；
- **斜边处允许料略微超出边框带、允许相邻料重叠**（直矩形无法正好贴满斜向的带），这只是记录，不作为错误。

实测算例（`异形图.dxf`，竖向受力）：

| --- | --- |
| 凹口梯形（图形 5） | 顶边 289.919 + 927.978；底边 991.52；左斜 1084.311；右斜 1147.268；缺口封口 180（盖住两侧）；缺口两侧 145 x2（让位） |

### 7.1.4 缺口附近的条（纯偏移模型）

**偏移作用于整个轮廓，缺口不需要单独定规则**：

```text
板件轮廓   = 原始轮廓（含缺口）向内偏移 缩尺
排条区轮廓 = 板件轮廓再向内偏移 一个边框厚     ← 这就是真正的排条区域
```

缺口在两次偏移里自然跟着变：**开口变宽**（每侧各一个偏移量）、**深度从板件边量起不变**。排条只用同一个排条区轮廓判定：

1. **条带 ∩ 排条区轮廓**：用"整宽"判定（`ClipBand`）——条带必须整宽落在排条区内，否则按短边切平，保证条不超出内边框线；
2. **条带 − 缺口（偏移两次后的缺口净空）**：用"并集"判定（`TryClipBandUnion`）——条带宽度方向与缺口净空有任何重叠（含只压一半）就按并集区间挖掉。

不做额外的"clearance 外扩"和"退端/切断"特判：那些会把只是站在缺口旁边的条也切掉，属于多余规则。

### 7.1.5 图形分流

- 轮廓的边**全是水平/竖直**（矩形、带缺口/缺角的矩形）→ 走**原有矩形路径**；
  凸包会把缺角"桥"出一条对角线，用凸包拆分会在图上凭空多一根斜线，所以这类必须走矩形路径。
- 轮廓含**斜边**（梯形、平行四边形、带缺口梯形）→ 走多边形路径（凸包 = 基准轮廓，包内顶点链 = 缺口）。

### 7.1.6 核对工具

- `GridTest.exe --outline` 会为每个排条成功的图形生成 SVG（`docs/svg/图形N（宽x高）.svg`）：
  红 = 外轮廓（含缺口）、灰 = 内边框（含缺口）、蓝 = 基准边料、橙 = 缺口料，料中间标下料长度；
- 每根缺口料都断言"内长边贴内边框线、外长边贴外边框线"，缺口料不参与该断言。

## 8. 标注

- 边框标注：每条边中点沿外法线 15mm 放文字，文字旋转平行于边。
- 横/纵条长度标注：放在段中点，方向与条一致。
- 首尾孔距标注：沿用现有横/纵首尾孔距逻辑，坐标来自多边形裁剪后的段。

## 10. 边界与限制

- 只支持直线边凸轮廓：矩形、梯形、平行四边形。
- 弧形轮廓（半圆缺口、扇形异形等）：待定，检测到 `bulge` 时拒绝并提示。
- 凹轮廓 / 带缺口的梯形：下一阶段（多边形布尔差）。
- 自相交轮廓先拒绝并提示。
- 网格保持正交，斜边截断按 6.1 取短边切平，不产生斜口料；若以后要求条平行斜边，再加网格旋转选项。
- 条的方向、边框横/竖归类都按图纸方向；图形整体旋转不影响结果（第 4 节）。
- 四条边全斜（无近水平/近垂直边）时按第 7 节的兜底规则归类。
