# 钢格板自动排条 · 项目进度与交接

> 最后更新：2026-10-13　当前版本：**2.2**
> 用途：新开会话窗口时先读这一份，能直接接手剩余任务。

## 1. 项目现状（一句话）

AutoCAD .NET 插件（C#，.NET Framework 4.8 / AutoCAD 2020），框选闭合轮廓后自动生成排条图：**边框料 + 纵横条 + 首尾孔距标注 + 下料表 + 分组框**。
Python 版已删除，仓库现在只有插件一套代码。

支持范围：

| 图形 | 状态 |
| --- | --- |
| 矩形（凹口 / 缺角 / 凸出） | ✅ 走原有矩形路径（一代一代改出来的，**不要轻易动**） |
| 梯形 / 平行四边形（含整体旋转） | ✅ 多边形路径 |
| 带缺口 / 缺角的梯形（含**斜边上的缺口**） | ✅ 多边形路径 |
| 弧形（半圆缺口、扇形） | ⏳ 识别后提示“弧形暂不支持”并跳过 |

## 5. 核心设计规则（改代码前先看这节）

### 5.1 区域模型（用户反复强调的“底层逻辑”）

```text
外框线 = 原始闭合轮廓（含缺角/缺口）向内偏移 缩尺
内框线 = 外框线再向内偏移 一个边框厚
排条区域 = 内框线以内          ← 所有排条规则都在这里
边框矩形区域 = 内外框线之间的带  ← 所有边框料都在这里
```

- 偏移是**对整个闭合轮廓直接偏移**（`Polygon.Offset`：每条边沿内法线平移 d，相邻偏移线求交 → 斜接自然处理），**不拆凸包、不拆缺口**。
- 缺口净空区 = 缺口**逐边沿各自外法线向外偏移**（`Polygon.OffsetOutward`）：
  - 板件缺口偏移 `缩尺`；排条区缺口偏移 `缩尺 + 边框厚`。
  - ⚠️ 不能用“沿开口方向加宽 + 沿基准边法线整体平移”：那只在开口垂直于侧壁时成立，**斜边缺口会算错**（历史 bug）。

### 5.2 边框料（每条边一根）

取该边两端的两组交点：内框线交点 `a`、`b`，外框线交点 `A`、`B`；沿**该边自身方向**量跨两端四段距离 `|AB|`、`|ab|`、`|Ab|`、`|aB|`：

- **包边方向取最大值**（垂直受力时横边包纵边），**被包方向取最小值**（让位）；水平受力时对调；
- 料的落位：包边以外框线为基准、被包以**内框线**为基准（两条线的起点相差一个边框厚，用错基准会整体偏 5mm —— 历史 bug）；
- **允许**料略超出边框带、允许相邻料重叠（直矩形无法正好贴满斜向的带），不作为错误。

实测算例（`异形图.dxf`，竖向受力）：

| 图形 | 边框料 |
| --- | --- |
| 凹口梯形 | 顶边 289.919 + 927.978；底 991.52；左斜 1084.311；右斜 1147.268；缺口封口 180；缺口两侧 145 ×2 |
| 缺角梯形 | 缺角横边 302.215（盖住两侧）；缺角竖边 154.92（让位）；底 991.52；顶 1087.978；右斜 1147.268；竖壁 919.647 |

### 5.3 排条

- **中心距布置范围** = 原始轮廓包围盒 缩进 `(缩尺 + 边框厚)`（与矩形路径一致）。⚠️ 不要用净空多边形自己的包围盒：缺口会把包围盒顶边压低，整排条会位移。
- 条带裁剪：`Polygon.ClipBand`（**整宽**判定，条不能超出内框线，超出按短边切平）；
- 挖缺口：`Polygon.TryClipBandUnion`（**并集**判定，只要条带和缺口净空有任何重叠就挖掉，只压一半也算）；
- 斜边被截断的条按**短边切平**下料（`BandCut` 保留理论两端 `RawStart/RawEnd` 供自检）。

### 5.4 孔位与标注

- 端距 < `边框厚 + 该条厚/2`（5mm 条 + 5mm 边框 → 7.5mm）的孔**直接不生成**；竖向受力时只截断横条、不截断纵条；
- **首孔距画在靠上一端、尾孔距画在靠下一端**。
  ⚠️ 多边形路径局部坐标是 **Y 向上**（矩形路径是 Y 向下），所以按 A/B 端直接放会把首尾画反 —— 历史 bug。

### 5.5 图形分流（GPGRID）

```text
轮廓全部是水平/竖直边（矩形、带缺口/缺角的矩形） → 原有矩形路径
轮廓含斜边（梯形、平行四边形、带缺口的梯形）      → 多边形路径
含弧段（bulge != 0）                              → 提示“弧形暂不支持”并跳过
```

原因：凸包会把缺角“桥”出一条对角线，多边形路径会把这条不存在的斜边当成板边（历史 bug）。

## 7. 历史踩坑（都是真踩过的，改代码时避开）

1. 凸包把**缺角**桥成对角线 → 图上凭空多一根斜料；对策：补回真实角点 + 全 h/v 轮廓走矩形路径。
2. `NotchedOutline` 绕缺口方向写反 → 边框线把缺口“填平”。
3. 缺口净空用“整体平移 + 沿开口加宽” → 斜边缺口附近条逐渐压到边框上；对策：`OffsetOutward` 逐边外法线偏移。
4. 排条范围用了净空包围盒 → 缺口让整排条位移 5mm。
5. 边框料位置基准线用错（被包却用外框线原点）→ 整根料偏 5mm。
6. `ClipBand` 是“整宽”语义，用它判缺口会漏掉“只压一半”的条 → 挖缺口必须用 `TryClipBandUnion`。
7. `Polygon.Outset`（负数半平面裁剪那版）实际不生效，已废弃，改用 `OffsetOutward`。
8. 局部坐标 Y 向上 vs 矩形路径 Y 向下 → 首/尾孔距标注会颠倒。
9. 生成排除缺口时别把“贴边界的点”算成进入缺口（判定要内缩 0.05mm）。

## 8. 剩余任务

见 `docs/待优化事项.md`，要点：

- **弧形 / 扇形支持**（下一步候选）：弧段离散成折线或做弧-带求交，套用现有内外框线规则。
- 旧式实体兼容（`POLYLINE`、闭合 `REGION`、闭合样条）。
- 内部孔洞识别（板中间的开孔，现在会被当普通板）。
- 标注智能避让、窄缺口标注适配（现在缺口的标注是就地放，窄缺口可能压住排条区）。
- 批量进度与 Esc 中断；非闭合/无效多段线的跳过反馈。
- 菜单 / Ribbon（`PackageContents.xml` 已备）、导出下料清单（Excel/CSV）。
- 非闭合 / 无效轻量多段线会逐个提示，批量结束时汇总无效、弧形跳过及处理失败数量。

## 9. 与用户协作的约定

- 用户是**行家**（钢格板生产工艺），规则以他给的为准；**先按“矩形路径是怎么做的”对齐**，别自创。
- 改动顺序：**先改 Core → 跑离线自检 → 看生成的 SVG → 用户确认 → 再编译插件**。
  用户明确说过“**先别生成插件**”“先给 SVG 我看看”，照做。
- 交付时：升版本号 + 新目录 + README 更新记录 + 一句“`NETLOAD` 哪个路径验证什么”。
- 用户反馈通常很具体（哪根料、哪条线不对），**不要猜**：把坐标/长度数据打出来对比。
- 矩形路径的既有输出（`三个图形.dxf`）**不能变**，每次都要回归。
