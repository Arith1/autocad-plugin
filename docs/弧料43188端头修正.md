## 原因与处理

旧路径将相邻直边平行的单弧进入半圆端部处理。对于此图的近切线凸弧，该处理在垂直受力时求不到交点，于是插件退回CAD原生偏移路径。通用路径原先直接连接两条偏移弧的各自端点，未独立切平弧料端面；水平受力的常规路径也存在直接使用原弧端点的情况。

新增 `ArcFrameEndAligner`，仅处理有近切线直边接头的单根凸弧：

1. 近切线接头（原弧切线与相邻直边夹角不超过1°），按垂直于相邻直料的截面切平，避免用切线去求另一半径圆的交点。
2. 另一普通转角按原直料的包边/被包关系，沿对应内框或外框直线切平。
3. 只调整 `CurvedFramePiece.PlateArc / NetArc` 的料带端头，`OutlinePlateArc / OutlineNetArc` 保留原对象；计料仍取两条弧边中较长者。
4. 在通用原生偏移路径，以及常规路径原端部处理成功后调用。原失败/回退路径不改变，避免切换排条所使用的几何流程。
5. 原凹弧、整圆、多弧组合及既有半圆/扇形/圆弧缺角规则保留。

`43188` 应表现为：上端竖直平口，下端水平平口。按缩尺5、框厚5复现，下端原内外弧端点差约(-6.028491,-5)，修正后垂直受力为(-5.092048,0)，水平受力为(-5.083506,0)。上端保持约5mm宽，不额外加余量。
