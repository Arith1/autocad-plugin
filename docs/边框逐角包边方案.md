# 边框逐角包边方案

日期：2026-10-19。状态：设计提案，尚未应用到插件。

## 当前采用方案：面向常见生产异形

用户希望优先覆盖实际生产中的绝大多数常见异形，不为极少见的复杂轮廓持续扩大算法。本轮以“两端向中间推进 + 夹角约束 + 实际端部计算”为实施方向。

“99%”是使用目标，尚无图纸样本统计支持，不能标记为已达到的覆盖率。

**本节优先于下文旧版推演。第 1～11 节保留为讨论记录，其中“单向从下往上”和“每个角必须有唯一包边方”不再作为统一要求。** 其中内外框投影计算、凹凸角区别及反例仍可参考。

### A. 受力方向决定推进方向

| 受力方向 | 推进方式 | 起始侧 | 对侧 |
| --- | --- | --- | --- |
| 垂直 | 底部向上、顶部向下，向中间推进 | 底边 | 顶边 |
| 水平 | 左侧向右、右侧向左，向中间推进 | 左边 | 右边 |

起始边优先包两端；对侧边具有包边作用即可：允许一端被包、另一端包边，不强求两端都包。双方直接相邻时优先保留起始侧在公共角的关系，对侧保留另一包边端。

多条底边、顶部为尖点或斜边等情况，需要在实际样例中明确对应的边及推进起点，不能把任意最高顶点直接当成一根水平顶边。

### B. 相遇角按夹角判断，不强制所有角都一包一被包

夹角 θ 指从连接点指向两根相邻料另一端的射线所形成的较小夹角，范围为 0°～180°。

| 夹角 | 连接处规则 |
| --- | --- |
| θ < 45° | 允许两个端部都被包，不强制指定包边方 |
| 45° ≤ θ ≤ 135° | 必须一端包边、另一端被包 |
| θ > 135° | 允许两个端部都被包，不强制指定包边方 |

范围外允许保留已有的一包一被包关系。角度判断使用未作显示舍入的几何值，并统一处理浮点容差。

六边形示例中，底料与顶料分别包边，中间四根料都可以作为被包边料；两路在 F、C 相遇后，只有夹角落入强制区间时，才必须调整其中一个连接端为包边。调整不自动改变该根料的另一端。

### C. 包边身份与实际端部长度分开计算

- 保持方切端头，允许相邻料在连接角处局部搭接。
- 双被包不等于两根都机械地取最短；仍要根据内外框和连接几何计算端部位置，避免缺料。
- 凹角和凸角可共用夹角规则，但端部投影、延长或回缩必须区分实际几何。
- 同一根料两端共同决定最终长度；角度关系满足后，还需确认正料长和角部覆盖。
- 几何保留计算精度，图面与报表显示最多一位小数。

### D. 本轮范围与验证顺序

优先处理矩形、三角形、梯形、普通多边形、斜边组合及常见开口缺口。先用于有效且内外边可对应的直线轮廓；已通过 CAD 验收的弧形路径继续保留，内部孔洞暂缓。

偏移后边消失、内框分裂或轮廓无效等特殊情况，明确提示原因，不能悄悄输出缺料的边框表。用户可另用 `GPGRIDNOBORDER` 完成该轮廓的直接排条，不能由 `GPGRID` 静默切换命令语义。

后续先在 Core 实现并生成带角部放大的预览，以常见样例及 `异形1.dxf` 中适用轮廓检查包边、料长与方向；用户确认后再编译新版本交 CAD 验收。保留旧版本和工作区已有成果。

以下为旧版推演及反例记录。

## 1. 方案结论

采用“从下往上选包边料 → 逐角补齐归属 → 根据内外框计算两端长度 → 检查角部缺料”的流程。

核心是：**包边关系记录在每一个角上，同一根料的两端分别决定。** 一根料允许两端包边、两端被包，或一端包边另一端被包。

用户提出的底边优先规则作为主规则；增加末尾补角步骤，解决三角形顶角等仅靠标记相邻边会遗留的问题。

本方案用于下料和装配关系分配，不构成承载能力计算。

## 2. 已确定的工艺与几何条件

- 原始轮廓向内缩尺得到外框，再向内偏移一个边框厚度得到内框。
- 真实转角处分料，连续共线段按一根料处理；弧形保持整根，不按离散弦段拆料。
- 直料采用方切端头，不设计斜切端头。
- 按用户说明，允许斜料与相邻直料在角部局部搭接，不以消除全部重叠为目标。
- 垂直受力时，在图形世界坐标中从下往上处理，不随最长边或斜边旋转判断方向。
- 内部挖孔暂不纳入本轮。
- 几何计算保留精度，仅输出尺寸保留最多一位小数。

第一阶段适用范围：单一闭合、无自交、由直线组成，且内外偏移边能够一一对应的轮廓。包括三角形、凸多边形和带凹缺口的多边形。

半圆缺口、双弧扇形、矩形圆弧缺角等已验收路径先保留。直线与圆弧相接时可以沿用逐角归属思想，但圆弧长度和端部处理必须另设适配，不能直接使用本文直料公式。

## 3. 两类状态必须分开

| 状态 | 用途 |
| --- | --- |
| 整根边是否可以继续作为“优先包两端”的候选 | 实现底边选中后暂不选择它的邻边 |
| 每个角由哪一根相邻料包住 | 最终决定该角两根料的端部处理 |

例如矩形：底边选中后，左右边退出优先候选，但只确定它们的下端被包。左右边的上端仍待分配，随后由顶边包住。

不能把“这根边已标记”理解为“这根边两端都已处理”；也不能立即让它拿尚未处理的上端重新参加底边选择，否则会抢先决定矩形上角。

每个角记录唯一包边方、相邻被包方及分配原因。稳定标识来自几何位置，不使用多段线起点编号作为优先依据。

## 4. 第一步：从下往上选包两端的边

### 4.1 明确定义“最下面”

建议按以下顺序比较直线边：

1. 两个端点的最低 Y，较低者优先。
2. 两个端点的最高 Y，较低者优先。这样水平底边会排在从同一底点向上延伸的边之前。
3. 水平跨度，较大者优先。
4. 中点 X，较小者优先，作为同高度对称情况的固定选择。
5. 规范化后的端点坐标，作为最终稳定排序依据。

这是对“从下往上”的确定性约定，不代表唯一正确的生产排法。斜底边照样参加排序，无须强制让水平边、垂直边包住斜边。

排序使用几何容差下的统一坐标归并或量化；不能拿显示时的一位小数参与判断，也不能在排序比较器中随意使用不满足传递性的误差比较。

### 4.2 选边过程

按上述顺序遍历所有边：

1. 当前边若已退出候选，跳过。
2. 当前边两端的角都分配给当前边，即当前边优先包两端。
3. 两根邻边在相接端被包。
4. 当前边及两根邻边退出后续优先候选。
5. 继续寻找下一条候选边。

若有多条互不相邻的最低边，它们都可以选中。若两个最低边共用一个角，例如 V 形底部，则不能同时占有该角，按固定排序选其中一条。

## 5. 第二步：补齐剩余角

优先选边结束后，逐个检查仍未分配的角：

- 在这个角的两根相邻边中，按第 4.1 节相同的顺序选一根作为包边方。
- 只处理这个角，不更改已经分配的角，也不重新传播整根边的候选状态。

对于简单闭合边链，第一步选出的边彼此不相邻；每根未选中边至少有一端邻接已选中边，因此最多剩一个未分配端。第二步可以独立补齐这些角。

这样能保证**每个角恰好一个包边方**。它保证的是关系完整；实际方切矩形是否把角部覆盖完整，还要经过第 7 节的几何检查。

伪代码：

```text
规范化轮廓，建立边、角以及内外框对应关系
全部边设为可选，全部角设为未分配

for 边 in 从低到高的稳定顺序:
    if 边不可选: continue
    将边的两个角归属给该边
    禁止该边及左右邻边再次作为优先候选

for 角 in 全部角:
    if 角尚未分配:
        在两根相邻边中按稳定顺序选择包边方

按每根边的两个端部状态生成方切料
检查角部缺料，必要时做有界端部延长
生成图形与下料表
```

## 6. 第三步：计算每根料的实际长度和位置

### 6.1 使用对应的四个端点

将外框规范化为逆时针。某根直料对应：

- 外框端点 O0、O1。
- 内框对应端点 I0、I1。
- 外框单位切向量 e，朝向内部的单位法向量 n。
- 外框长度 L，边框厚度 T。

以内外边的实际投影计算：

```text
o0 = 0
o1 = L
i0 = dot(I0 - O0, e)
i1 = dot(I1 - O0, e)

起端包边：s = min(o0, i0)
起端被包：s = max(o0, i0)

末端包边：t = max(o1, i1)
末端被包：t = min(o1, i1)

料长 = t - s
中心 = O0 + e × ((s + t) / 2) + n × (T / 2)
```

根据中心、方向、料长和厚度生成普通方切矩形。计算前确认内外对应直线平行、间距符合 T。

### 6.2 凹角不能直接套“外长内短”

凸角处通常外框端点伸得更远；凹角处可能是内框端点伸得更远。因此取实际投影极值，不写死“包边取外框长度、被包取内框长度”。

两端分别计算，也避免一端包、一端被包时错误切换整根料的定位基准。图形和下料表共用同一份最终料件数据。

## 7. 第四步：允许搭接，检查缺料

斜角处，一长一短的两根方切矩形不一定刚好覆盖完整角部。不能仅靠包边标记就宣称没有缺口。

建议采用以下处理：

1. 以内外框之间的实际区域作为目标边框区域。
2. 检查初算料件的并集是否遗漏角部区域，过滤几何容差内的微小误差。
3. 若被包端回缩造成实际缺料，允许它在对应端点的长短投影范围内适量伸长，与包边料局部搭接。
4. 延长仅作用于发生缺料的端部。以覆盖检查求最小必要延长量，不凭经验额外加固定毫米数。
5. 达到该端较长投影位置仍无法覆盖，或料长已非正数，返回具体边号、角号及原因，不能无限延长或漏掉该根料。

此处“被包”表示装配关系，不要求它在所有斜角情况下都取数学上的最短长度。最终允许的局部搭接在预览中明确画出。

有效对应的边框侧面四边形可用于定位缺料和确定延长范围；偏移边消失、分裂或对应关系错乱时，必须先判为不适用，不能靠延长掩盖。

普通直角矩形应保持既有输出。斜角处不以“全部料件严格位于框带以内”或“交叠面积为零”作为通过标准；远离连接角的异常越界、非相邻边相交仍需单独提示。

## 8. 三种图形的推演

### 8.1 三角形

坐标：A(0,0)、B(100,0)、C(50,80)。

1. 底边 AB 优先包住 A、B，斜边 BC、CA 的下端被包。
2. 两根斜边退出优先候选，顶角 C 尚未分配。
3. 补角时，CA 与 BC 高度和跨度相同，CA 中点更靠左，由 CA 包住 C。

| 料 | 起端 | 末端 |
| --- | --- | --- |
| AB | A 包边 | B 包边 |
| BC | B 被包 | C 被包 |
| CA | C 包边 | A 被包 |

若底边为斜边，仍按几何高度选边，不强制轴向边优先。

### 8.2 房子形五边形

依次为 A(0,0)、B(100,0)、C(100,80)、D(50,120)、E(0,80)。

1. AB 包住底部 A、B；左右立边退出候选。
2. 两根屋顶斜边中，DE 按同高度靠左规则先选中，包住 D、E。
3. 剩余 C 由 BC 和 CD 竞争；BC 的最低端更低，C 归 BC。

| 料 | 起端 | 末端 |
| --- | --- | --- |
| AB | A 包边 | B 包边 |
| BC | B 被包 | C 包边 |
| CD | C 被包 | D 被包 |
| DE | D 包边 | E 包边 |
| EA | E 被包 | A 被包 |

这个例子说明奇数条边也能分配完整，无须强求整圈长短交替。

### 8.3 顶部有矩形缺口的矩形

```text
H────G         D────C
│    │         │    │
│    F─────────E    │
│                   │
A───────────────────B
```

坐标：A(0,0)、B(100,0)、C(100,100)、D(70,100)、E(70,60)、F(30,60)、G(30,100)、H(0,100)。

1. 最底部 AB 包左右外立边下端。
2. 缺口底边 EF 包两根缺口立边的下端。
3. 两段顶部肩边 GH、CD 包对应立边的上端。
4. 全部角均已分配，无须补角。

结果：四根横料两端包边，四根竖料两端被包。E、F 是凹角，缺口底料可能按内框的更远端点延长。

侧向缺口、底部缺口也按完整闭合轮廓参与上述流程，但不能直接照搬这个“横包竖”的结果，需要逐角计算并预览。

## 9. 建议落地顺序

1. **独立实现角归属计算。** 输入真实边链，输出每个角的归属和原因；不掺入绘图、报表和偏移算法。
2. **实现直料端点投影计算与角部覆盖检查。** 先在 Core 中产出料件数据和离线预览。
3. **生成可审阅预览。** 按料件着色、标注边号和角号，分别显示包边关系、允许搭接、实际缺料，并提供角部放大图。
4. **审阅样例后接入通用异形路径。** 取代三角形单独按角度抢占包边的临时规则，复用统一逐角规则。
5. **保护正式基线。** 普通矩形及已验收弧形路径先保持；纯直线新路径确认与旧矩形结果一致后再考虑统一。
6. **再编译新版本交 CAD 验收。** 保留 v3.0、v3.03、现有 v3.04 产物，不覆盖旧版本。

水平受力可对称扩展为从左往右，将排序主轴从 Y 改为 X、次轴从 X 改为 Y；需在对应样例确认后启用。

## 10. 验收范围与当前证据

| 范围 | 核对内容 |
| --- | --- |
| 普通矩形 | 与原有输出一致，底边和顶边包两端 |
| 三角形 | 水平底、斜底、朝下尖角、不同斜率；顶角不遗漏 |
| 五边形及其他多边形 | 奇偶边数均可，混合端部状态位置正确 |
| 凹轮廓 | 顶部、底部、侧边缺口及多底边；凹角不取反长度 |
| 稳定性 | 改多段线起点和顺逆时针后归属不变；平移后关系不变 |
| 退化情况 | 短边、近共线、偏移边消失、分裂、自交都有明确原因 |
| 工艺输出 | 方切端头；允许角部局部搭接；没有可检测的角部缺料 |
| 一致性 | 绘图和料表来自同一结果，显示最多一位小数 |
| 实际样例 | 异形1.dxf 中可适用的直线轮廓逐个看料件及角部 |
| 回归 | 三个图形.dxf 及已验收弧形样例保持基线结果 |

方案整理时已用独立的临时计算推演上述三角形、房子形五边形、顶部缺口矩形的角归属，并枚举起点改变与绕向反转，三个样例的归属均保持一致。

该检查仅针对离散角归属，不代表实际料长、覆盖检查、异形1.dxf 全部图形或 CAD 插件已通过验证。本次仅新增方案文档，插件仍保持现有实现。

## 11. 反推审查：适用边界及必要修正

### 11.1 能证明的只有角归属完整

对有效的简单闭合边链，优先选边再补角可以让每个角恰好归属一根相邻料，不依赖边数是奇数还是偶数。

但这不证明该归属符合全部实际包边工艺，也不证明计算出的方切料能够覆盖角部。最低端点排序提供一种确定选择；在同高度的尖底、复杂凹口处，单靠排序没有足够的几何信息判断哪个方向更合适。

### 11.2 反例一：普通三角形也可能有角部缺料

取第 8.1 节三角形 A(0,0)、B(100,0)、C(50,80)，边框厚度 T=5。

偏移后的内框顶点约为：

```text
A' = (9.021238, 5)
B' = (90.978762, 5)
C' = (50, 70.566019)
```

按 AB 包住底部两个角、CA 包顶角，且严格按第 6 节长短投影生成三根方切矩形，点 (3.75, 5.25) 位于目标框带内，却不在任何一根料中：它已高于底料，而左斜料下端回缩后没有覆盖该处。

独立临时计算用点包含及矩形投影判定确认了这一反例；0.5 间距采样还发现其他未覆盖点。采样只用于发现反例，不用于证明整个区域已经覆盖。

结论：第 7 节的几何处理是必要步骤，不能只做归属计算就交付。允许搭接可为端部延长提供空间，但实际长度仍需求解。

### 11.3 反例二：短切角在偏移后消失

一个 100 × 100 的矩形，右上角切去 2 × 2 的三角形，其外框顶点为：

```text
(0,0), (100,0), (100,98), (98,100), (0,100)
```

切角斜边长约 2.828。向内偏移 5 后，按相邻偏移直线求得该段有向长度为：

```text
2√2 - 2 × 5 × tan(22.5°) ≈ -1.314
```

这表示原先的逐边偏移对应关系已经失效，不能把负数取绝对值继续作为有效内框边。正常修剪的内框中，该短切角约束会变成冗余，内框不再保留对应的切角边。

这个图形本身闭合、无自交、也无挖孔，仍然超出本方案的一一对应前提。原始外框切角料如何保留，需要支持多个外框边对应同一内框角的独立处理。

### 11.4 反例三：窄连接处的内框分裂

两个较大区域通过宽 8 的窄颈连接，边框厚度为 5。两侧各向内偏移 5 后，窄颈净宽已不足，内框可能分裂为两个区域。

此时外框仍是一圈，内框却不再是一圈。即使外框每个角都能分配包边方，原有一圈对一圈的端点公式也不能使用。这是偏移拓扑变化，不能用更换排序或延长某根料解决。

### 11.5 修正后的求解流程

将原方案“先固定关系，失败后仅提示”修正为：

1. **检查内外框。** 确认轮廓有效、对应关系成立。边消失、分裂等情况进入单独处理；当前尚未支持时给出明确原因。
2. **生成优先方案。** 仍按底边优先规则选择，保留用户的工艺偏好。
3. **逐角计算两种候选。** 分别考虑 A 包 B、B 包 A 的方切端部位置、覆盖以及必要搭接。
4. **合并相邻角的约束。** 同一根料的两端共同决定料长，不能只看一个角。原候选不成立时允许回退、换另一种归属，并重新计算受影响的料。
5. **整体几何检查。** 检查目标框带缺料、非相邻料异常干涉等。只有在局部端部约束充分、没有非局部相互影响时，才可以把问题简化为沿闭合边链选择每个角的两种状态。
6. **无可行结果则定位原因。** 不把“任意指定一个包边方”当成已经解决，不默默删除短料或修改原始轮廓。

如果生产规则要求某根底料必须包边，可把它作为不可更改的约束；若与几何条件冲突，应明确报出冲突。其他同高度排序只作为多个可行方案之间的偏好，不凌驾于几何可行性。

第 9 节实施时应采用此修正版流程。现阶段不能声称适用于全部图形，也未据此验证异形1.dxf 的全部轮廓。圆弧仍按第 2 节另行适配，内部孔洞继续暂缓。
