# AutoCAD 插件骨架

这个目录是 AutoCAD .NET 插件的 C# 工程。核心算法放在 `SteelGrid.Core`，AutoCAD 交互放在 `SteelGrid.Plugin`。

## 结构

```text
autocad-plugin/
├─ SteelGrid.CadPlugin.sln
├─ src/
│  ├─ SteelGrid.Core/          # 纯算法，不依赖 AutoCAD
│  └─ SteelGrid.Plugin/        # AutoCAD 命令、菜单、面板
└─ package/
   └─ PackageContents.xml
```

设计文档：

```text
docs/
└─ 凸凹图形排条解决方案.md   # 凸出/凹凸混合图形的排条处理方案
```

## AutoCAD 版本

当前按 AutoCAD 2020 准备，目标框架为 `.NET Framework 4.8`，平台 `x64`。

## AutoCAD 引用

`SteelGrid.Plugin.csproj` 使用环境变量 `ACAD_2020_ROOT` 定位 AutoCAD 安装目录；未设置时会使用当前机器的默认路径。

引用这些 DLL：

```text
$(ACAD_2020_ROOT)\acmgd.dll
$(ACAD_2020_ROOT)\acdbmgd.dll
$(ACAD_2020_ROOT)\accoremgd.dll
```

在系统环境变量中设置，例如：

```text
ACAD_2020_ROOT=D:\CAD\AutoCAD\AutoCAD 2020
```

AutoCAD 2020 如果 API 目录相同，也可以使用这个变量。

## 当前已实现

- `BarType` 支持 `扁钢` 和 `扭绞方钢`
- 板件、净空、缺口几何计算
- 纵横扁钢布置、截短、分段、孔位计算
- AutoCAD 命令骨架：
  - `GPGRIDSET`：打开参数面板
  - `GPGRID`：选择闭合轮廓并生成基础排条实体
  - `GPGRIDINFO`：显示当前算法版本

AutoCAD 专用部分需要在装有 AutoCAD 2020 的机器上编译调试。

## 更新记录

### v0.16 - 2026-09-17

- 边框标注全部改到整体钢格板外轮廓外侧 `110` 处：
  - 顶部水平尺寸标在板外上方、底部在板外下方、左/右垂直尺寸在板外左/右侧。
  - 缺口内的封口宽度等尺寸用延伸线引到板外，不再落进排条区。
- 缺口深度每个缺口只标注一次，标注线放在缺口开口正中心（横向居中），不再左右两侧重复标注。

### v0.15 - 2026-09-17

- 顶/底缺口封口宽度按受力方向区分：
  - 垂直受力（水平边包垂直边）：封口取 `缺口净宽 + 2 x 边框厚`（示例 350、120）。
  - 水平受力（垂直边包水平边）：封口取 `缺口净宽`（示例 340、110）。
- 边框下料表的封口宽度同步按受力方向取值，与图形一致。

### v0.14 - 2026-09-17

- 缺口边框料全部改到缺口壁的材料侧，不再伸入缺口开口：
  - 顶/底缺口：左侧料左移一个边框厚、右侧料右移一个边框厚、封口料向板件内侧移一个边框厚。
  - 左/右缺口：内侧立板移到缺口远壁的材料侧，上下封口移到缺口上/下壁的材料侧。
- 边框下料表与缺口矩形尺寸对齐：
  - 顶/底缺口侧料长度按受力方向取 `缺口深度 - 边框厚`（垂直）或 `缺口深度 + 边框厚`（水平）。
  - 顶/底缺口封口宽度取 `缺口净宽 + 2 x 边框厚`。
  - 水平受力时，顶部/底部水平段按缺口净宽两侧各外扩一个边框厚截取，与图形一致。

### v0.13 - 2026-09-17

- 修复边框料矩形参数错位：`Rect` 构造参数为 `(x0, y0, x1, y1)`，此前 `DrawFramePieces` 按 `(x, y, 宽, 高)` 传参，导致除顶部左段 `410 x 5` 和左边框 `5 x 1215` 外，其余边框矩形尺寸为负而被跳过。
- 修正后 `1850 x 1240`、缩尺 `5`、边框 `5`、垂直受力生成 12 个边框矩形：
  - 顶部 `410/500/480 x 5`，底部 `1840 x 5`，左右 `5 x 1220`。
  - 缺口两侧 `5 x 185` x4，封口 `350 x 5` 和 `120 x 5`。
- 水平受力同样完整生成 12 个矩形：左右 `5 x 1230`，顶部 `400/490/470 x 5`，底部 `1830 x 5`，缺口两侧 `5 x 195` x4，封口 `350 x 5` 和 `120 x 5`。

### v0.12 - 2026-09-17

- `GPGRID` 运行时打印识别结果，便于排查：板件尺寸、缺口数量及每条缺口的位置/宽度/深度、受力方向。

### v0.11 - 2026-09-17

- 修正水平受力时顶部/底部水平边框段的长度：缺口两侧按缺口净宽各外扩一个边框厚度参与截取，使顶部段与缺口侧边框料对齐。
  - 示例 `1850 x 1240`、缩尺 `5`、边框 `5`：顶部左/中/右段由 `405/500/475` 修正为 `400/490/470`。
  - 缺口净宽 `340/110` 对应封口料 `350/120` 保持不变。
- 明确钢格板外框线即缩尺后板件最外侧边界（含缺口）：缺口左侧外框线到右侧外框线的距离就是缺口净宽，不另加边框厚度。

### v0.10 - 2026-09-17

- 参数面板改为统一样式：`字段名: 输入框`。
- 新增受力方向选项，支持 `垂直 / 水平`。
- 参数面板新增并单独展示横向厚度、横向中心距、纵向厚度、纵向中心距。
- 核心模型新增 `LoadDirection` 参数。
- 参数设置从 AutoCAD 停靠面板改为独立窗口，避免字段被面板宽度压缩。
- 参数行改为固定行布局，确保每个标签与对应输入框在同一行完整显示。
- 参数窗口增加“保存参数”按钮；保存后写入本地配置并自动关闭窗口。
- 保存参数时窗口为模态状态，避免用户在填写参数时操作图形。
- 边框下料逻辑改为按受力方向决定包边顺序：
  - `垂直受力`：上下水平边包住左右垂直边。
  - `水平受力`：左右垂直边包住上下水平边。
- CAD 图形中的边框不再绘制成整体内外轮廓，而是按受力方向拆分为独立边框料矩形，能直观看出哪条边包住哪条边。
- 顶部缺口两侧的边框矩形改为从外边框顶部延伸到缺口底部，避免缺口角部漏掉边框料。
- 顶部/底部缺口封口边框宽度改为包含两侧边框厚度，例如缩尺后缺口 `340` 对应封口 `350`，缺口 `110` 对应封口 `120`。
- 水平受力时，顶部/底部缺口两侧边框高度按 `缺口深度 + 边框厚度` 计算，封口宽度仍为 `缺口宽度 + 2 × 边框厚度`。
