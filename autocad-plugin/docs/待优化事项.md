# 插件待优化事项

记录钢格板自动排条插件后续优化方向。按对实际使用的影响排序。

## 一、健壮性（建议优先）

| 事项 | 说明 | 优先级 | 状态 |
| --- | --- | --- | --- |
| 旋转/倾斜图形支持 | 当前 `OutlineReader` 假设轮廓横平竖直；图纸整体旋转后识别会出错。移植 Python 版基于最长边建立局部坐标系的归一化逻辑。 | 高 | 未开始 |
| 旧式 POLYLINE 兼容 | 目前只识别 LWPOLYLINE；旧式 `POLYLINE`、闭合 `REGION`、闭合样条会被跳过且无提示。 | 高 | 未开始 |
| 内部孔洞识别 | 当前空洞检测只找贴外边缺口，板中间矩形开孔会被当成普通板处理。 | 中 | 未开始 |
| 批量跳过反馈 | 批量时被跳过的非闭合/无效多段线没有反馈，最后应提示“选中 N 个，跳过 M 个”。 | 中 | 未开始 |

## 二、出图与下料表

| 事项 | 说明 | 优先级 | 状态 |
| --- | --- | --- | --- |
| 首尾孔距多组值一致 | 同一规格长度存在多组首尾孔距时，表格显示 `35/38` 并列，图上只标数量最多的一组；应每组都标，或表格只显示图上标的那组。 | 高 | 未开始 |
| 表格列宽自适应 | 固定列宽下 `扭绞方钢 5x5` 等规格和长数字可能溢出单元格；按内容自适应或允许换行。 | 中 | 未开始 |
| 标注智能避让 | 当前靠固定偏移和旋转避让，复杂图形仍可能撞字；升级为碰撞检测，必要时加引线，或首尾孔距文字改用 MText 背景遮罩。 | 中 | 未开始 |

## 三、批量流程

| 事项 | 说明 | 优先级 | 状态 |
| --- | --- | --- | --- |
| 批量进度与中断 | 大批量生成时无进度反馈，易被误认为卡住；按图形输出“3/20 完成”，并支持 Esc 中断。 | 中 | 未开始 |
| 每行/列数量可配置 | “10 个一行/一列”目前写死，应在输出选项里让用户填写每行/每列数量。 | 低 | 未开始 |

## 四、代码与维护

| 事项 | 说明 | 优先级 | 状态 |
| --- | --- | --- | --- |
| 识别算法下沉 Core | `GridTest` 里的识别逻辑是 `OutlineReader` 的复制品，易漂移；把“多段线顶点 → 空洞列表”下沉到 `SteelGrid.Core`，插件与测试共用。 | 中 | 未开始 |
| 拆分 DrawResult | `DrawResult` 承担边框、扁钢、标注、表格、分组框全部绘制，拆成职责明确的方法。 | 低 | 未开始 |
| 集中硬编码常量 | 110/50/10/250 等间距分散在代码中，集中为常量或放进输出选项。 | 低 | 未开始 |

## 五、部署与集成

| 事项 | 说明 | 优先级 | 状态 |
| --- | --- | --- | --- |
| 菜单/工具栏 | 目前只有命令；增加 Ribbon 按钮（`GPGRID`/`GPGRIDSET`），配合 `PackageContents.xml` 做 Bundle 安装。 | 中 | 未开始 |
| 导出下料清单 | 批量完成后可选导出 Excel/CSV 下料清单，与 Python 版功能对齐。 | 低 | 未开始 |

## 建议实施顺序

1. 旋转图形支持 + 旧式 POLYLINE 兼容 + 批量跳过反馈。
2. 首尾孔距多组值一致、表格列宽自适应。
3. 识别算法下沉 Core、批量进度与中断。
4. 其余按实际需求逐步推进。
