# 钢格板异形轮廓排条方案（直线边 + 弧边 / 弧缺口）

## 1. 异形图样例分析（异形图.dxf）

`异形图.dxf` 模型空间有三条闭合 `LWPOLYLINE`，是钢格板常见的异形（DXF 轮廓为原始洞口，未缩尺）：

| 图形 | 尺寸 | 轮廓特征 |
| --- | --- | --- |
| 1 | 1000 × 1200 | 矩形板，底部右端有 150 弦长半圆缺口（`bulge = -1`，半径 75、深 75，弧向板内凹） |
| 2 | 上边 1300 / 下边 1000 / 高 1000 | 梯形板：左竖直边，右侧斜边（斜长 1044） |
| 3 | 上边 517.6 / 下边 181.2 / 高 627.9 | 扇形/异形板：右斜边向内弧（`bulge = +0.132`）、底边向下弧（`bulge = -0.132`）、左斜边为直线 |

共同点：

- 轮廓都由直线段和弧段混合组成，弧段通过多段线 `bulge` 编码。
- 图形 1 的弧缺口和图形 3 的凹弧边说明轮廓不一定是凸的，模型需要支持“带弧缺口的凹轮廓”。
- 图形内部的扁钢条仍是正交网格，条在斜边/弧边处被截短或斜切。

## 2. 统一模型：多边形 + 弧段

```text
PolygonRegion {
  vertices: Point2d[]       // 局部坐标，逆时针
  arcs: bool[]              // 每条边是否来自弧段
  bulge: double[]           // 弧段 bulge，直线边为 0
  bounds: Rect              // 包围盒，用于网格布置范围
}
```

读取阶段把弧段离散成折线，几何阶段面对“简单多边形（可含凹弧缺口）”：

- `bulge = ±1`：半圆，直接按 180° 采样。
- 其它 bulge：按弦高容差（默认 2mm）或步角（默认 5°）采样。
- 矩形：保留现有快速路径，不进入多边形路径，避免回归。

核心能力放 `SteelGrid.Core/Geometry/Polygon.cs`：

```text
PointInPolygon(p, poly)            // 点是否在多边形内
ClipSegmentToPolygon(seg, poly)    // 直线段被多边形裁剪（凹缺口会切成多段）
ClipBandToPolygon(center, halfW, axis, poly)  // 条带裁剪
InsetPolygon(poly, distance)       // 轮廓向内偏移（凹弧处按材料侧内移）
ArcToPolyline(p0, p1, bulge, tol)  // 弧段离散
PolygonNormal(edge)                // 每条边外法线，用于边框和标注
```

## 3. 识别（读取层）

1. 读闭合 `LWPOLYLINE` 的每个顶点 `(10,20)` 和 `bulge(42)`。
2. 旋转归一化：取最长直线边作为局部 X 轴，把轮廓转到局部坐标。
3. 把弧段按容差离散成折线，得到简单多边形。
4. 分类只用于提示：矩形 / 梯形 / 平行四边形 / 半圆缺口板 / 扇形异形板，几何路径统一。
5. 批量时三种图形混合处理，单个失败不中断。

## 4. 几何与净空

```text
板多边形 = 原始轮廓先按缩尺向内偏移（矩形缺口平移、尺寸不变；弧边半径随缩尺调整）得到的板件轮廓
净空多边形 = InsetPolygon(板多边形, 边框厚度)
```

- 缩尺：默认每边向内缩 5，得到钢格板外框（板件）。
- 直线边：沿内法线平移 `t`，相邻边求交得到新顶点。
- 弧边：离散段各自内移后重求交；弧缺口处净空沿弧向材料侧再内移一个边框厚（半圆缺口半径 75 时净空半径约 70）。
- 锐角/小半径处偏移可能产生极短边，用最小边长阈值清理。

## 5. 排条

沿用现有正交网格思想，把“矩形净空 + 缺口裁剪”换成“多边形净空 + 条带裁剪”：

- 纵条：中心 x 处竖直条带 `[x-t/2, x+t/2]`，用 `ClipBandToPolygon` 与净空多边形求交，输出 0..N 段。
- 横条：中心 y 处水平条带同理。
- 半圆缺口区域：纵条/横条进入缺口投影的段被弧边裁剪，自动截短或分段。
- 梯形/扇形斜边：条端斜切，段端点由裁剪自然得到。
- 满长/整长判定：段长接近净空在该方向的投影跨度时算满长。
- 孔位：纵条段 ∩ 横条段取交点，且落在净空多边形内；首孔距、尾孔距、孔数沿用现有逻辑。
- 中心距布置范围取净空多边形包围盒的投影跨度，`PlaceCenters` 不变。

## 6. 边框

矩形仍走现有 `FrameSplitter`；异形走 `PolygonFrameSplitter`，每条边一根料：

- 直线边：一根直料，长度 = 边长 + 两端搭接；斜边用旋转矩形绘制，下料表只记长度。
- 弧边：默认按离散段逐段下料，长度合计即弧长；可配置为整根弧料。
- 弧缺口（半圆缺口）：沿缺口弧边做厚度 `t` 的弧形带，放在材料侧（板内），与相邻直边料端部搭接。
- 包边顺序沿用受力方向：垂直受力时接近水平的边包住接近垂直的边，水平受力相反；斜边按与主方向夹角归类。
- 下料表增加可选标记：斜边 / 弧边。

## 7. 标注

- 边框标注：每条边中点沿外法线 15mm 放文字，文字旋转平行于边；弧边取弧中点的法线，标注弧长或离散段长。
- 横/纵条长度标注：放在段中点，方向与条一致。
- 首尾孔距标注：沿用现有横/纵首尾孔距逻辑，坐标来自多边形裁剪后的段。

## 8. 模块改造清单

| 模块 | 现状 | 改造 |
| --- | --- | --- |
| `OutlineReader` | 只认横平竖直边 + 矩形缺口 | 新增 `PolygonOutlineReader`：读顶点 + bulge、旋转归一化、弧段离散、形状分类 |
| `Spec / GeometryBuilder` | 外接矩形 − 矩形空洞 | 新增多边形分支，矩形路径保持不变 |
| `LayoutEngine` | 矩形净空 + 缺口裁剪 | 新增 `LayoutPolygon`：条带与多边形裁剪、交点孔位 |
| `FrameSplitter` | 轴对齐矩形带 | 新增 `PolygonFrameSplitter`：每条边一根直料/弧料，弧缺口做弧形带 |
| 绘图 | 轴对齐 `CreateRectangle` | 新增旋转矩形、任意多边形、弧带绘制 |
| 标注 | 矩形边法线 | 按多边形边中点法线定位，文字旋转平行边 |
| 表格 | 矩形料方向/长度 | 长度按实际边料，可选斜边/弧边标记 |
| `GridTest` | DXF 顶点 + 矩形空洞 | 扩展解析 bulge，加入异形图.dxf 三个用例 |

## 9. 边界与限制

- 第一版支持：矩形、梯形、平行四边形、带弧缺口/弧边的简单多边形。
- 自相交轮廓、优弧（圆心角 > 180°）先拒绝并提示。
- 多个弧缺口叠加或缺口过窄导致净空自相交时提示。
- 网格保持正交，斜边/弧边处条端斜切或截短；若要求条平行斜边，再加网格旋转选项。
- 圆弧离散精度同时影响排条段数和边框料数量，精度参数放入输出选项（默认 2mm 弦高）。

## 10. 实施顺序

1. 底层多边形能力：`Polygon.cs`（点包含、条带裁剪、轮廓偏移、弧离散），配套 `GridTest` 单测。
2. 读取层：顶点 + bulge 解析、旋转归一化、弧离散、形状分类。
3. 多边形路径端到端：几何 → 排条 → 边框 → 绘图 → 表格 → 标注。
4. 用 `异形图.dxf` 三个图形验收，并回归现有凹口/缺角/凸出矩形用例。
5. 复杂凹轮廓（多缺口、内部孔洞）：多边形布尔差，再叠加现有缺口语义。

## 11. 验收用例

- 半圆缺口板：1000 × 1200 底部右端半圆缺口，验证缺口弧料、缺口内净空、条段截短。
- 梯形板：上 1300 / 下 1000 / 高 1000 右斜边，验证斜边料长度、斜切、斜边标注。
- 扇形异形板：上 517.6 / 下 181.2 / 高 627.9，右斜边内弧 + 底边下弧，验证弧料离散段、条段裁剪。
- 回归：凹口 / 缺角 / 凸出三个矩形用例结果不变化。
