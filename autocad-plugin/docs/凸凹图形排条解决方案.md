# 凸出 / 凹凸混合图形排条解决方案

## 1. 现状与方案

已按“外接矩形 − 矩形空洞”模型实现（v0.17）：

- 几何模型统一为 `外接矩形 − 矩形空洞`，凹口、缺角（角部空洞）、凸出图形（外接矩形挖掉两个缺角）都归为矩形空洞。
- 空洞贴到板件的边由矩形位置自动判定（可同时贴两条相邻边，即角部空洞）。
- 边框拆分、排条、净空轮廓、外轮廓、边框标注都从空洞矩形推导，不再按每条边逐段识别轮廓。

验证用例（缩尺 5、边框 5）：

- 凹口：1850×1240 两个顶口，垂直/水平受力各 12 个边框矩形。
- 凸出：1000×1200 顶部两个缺角，垂直/水平受力各 8 个边框矩形。
- 凹口+缺角：1850×1240 顶口加右下缺角，垂直/水平受力各 14 个边框矩形。

## 2. 轮廓特征识别（读取层）

把每条边上的轮廓线段分成三类：

| 类型 | 含义 | 相对名义板边 |
| --- | --- | --- |
| 边线 | 与包围盒对齐的主边 | 就是名义板边 |
| 凹口 | 从板边向板内凹进的矩形 | 向板内侧 |
| 凸出 | 从名义板边向板外凸出的矩形 | 向板外侧 |

判定规则：

1. 对每条边，取最长（或出现次数最多）的外沿线段作为该边的**名义板边**基准。例如顶部中间凸出时，左右两段平边是名义顶边，中间高出的矩形是凸出。
2. 相对名义板边向板内侧偏移的矩形识别为凹口，沿用现有缺口逻辑。
3. 相对名义板边向板外侧偏移的矩形识别为凸出。
4. 特征贴到两条相邻边时标记为角部特征（如右下角缺口），按两条边的规则组合处理。

统一数据模型建议：

```text
EdgeFeature {
  edge,      // top / bottom / left / right / 角部组合
  start,     // 特征起点
  width,     // 特征宽度
  extent,    // 凹口=深度，凸出=高度
  kind       // 凹 / 凸
}
```

绘图约定提示：凹口必须是从板边向板内凹进去；`三个图形.dxf` 中 1000x1200 那张图目前画成顶部中间凸起，如果本意是 200 深凹口，需要把轮廓改画成从顶边凹下去。

## 3. 几何与净空（几何层）

板件有效区域：

```text
有效区域 = 名义包围盒 − 凹口 + 凸出
```

净空（排条区）由有效区域边界向内偏移一个边框厚度：

- 凹口处：净空沿凹口内壁再内偏一个边框厚，与现有逻辑一致。
- 凸出处：净空沿凸出外轮廓内偏一个边框厚，即排条区延伸进凸出部分。

用**局部边界函数**统一表达，避免为每个特征写特殊分支：

```text
top(x)    // 纵条在位置 x 的上边界
bottom(x) // 纵条在位置 x 的下边界
left(y)   // 横条在位置 y 的左边界
right(y)  // 横条在位置 y 的右边界
```

每个函数由“名义边 + 覆盖该位置的特征”决定：

- 无特征：名义边向内偏移一个边框厚。
- 凹口覆盖：取凹底（或凹口对侧壁）再内偏一个边框厚。
- 凸出覆盖：取凸出外端再内偏一个边框厚。

## 4. 排条（布条层）

- 纵条：中心 x 处的段区间 = `[top(x), bottom(x)]`；若区间被中间凹口切断，按现有分段逻辑拆成多段。
- 横条：中心 y 处的段区间 = `[left(y), right(y)]`，同样支持分段。
- 孔位、首孔距、尾孔距、孔数计算全部基于段区间，沿用现有逻辑。

凹凸混合示例：

- 顶部凹口 + 底部凸出：同一根纵条在凹口处截短/分段，在凸出处向板外延伸。
- 左侧凸出 + 右侧凹口：同一根横条在左侧延伸、在右侧截短。

## 5. 边框料（下料与绘图）

边框料沿有效区域外轮廓拆分，凹口和凸出都放在**材料侧**：

- 凹口：左壁、右壁、封口，尺寸按受力方向区分（垂直受力封口 = 净宽 + 2 x 边框厚；水平受力封口 = 净宽）。
- 凸出：凸出两侧壁 + 凸出外端封口，边框厚度与主边框一致；外端封口尺寸按同一受力规则取值。
- 角部：两条相邻边的规则组合，外侧边自然闭合，避免重复料。

受力方向包边顺序沿用：

- 垂直受力：水平边包垂直边。
- 水平受力：垂直边包水平边。

下料表沿用 `序号 / 规格 / 方向 / 数量 / 首孔距 / 尾孔距 / 孔数` 结构，凸出料与凹口料都进入边框下料表。

## 6. 标注（边框标注层）

- 所有标注线统一放在整体包围盒外侧 110 处：顶部尺寸在板外上方、底部在板外下方、左右尺寸在板外两侧。
- 凹口深度：每个凹口只在开口正中心标注一次。
- 凸出高度：每个凸出只在凸出中心标注一次。
- 凸出宽度等水平尺寸放进对应的外侧标注带，用延伸线从特征轮廓引出来，不进入排条区。

## 7. 实施步骤（已完成）

1. 扩展轮廓读取：边线 / 凹口 / 凸出分类，角部特征识别。
2. 几何层：统一“外接矩形 − 矩形空洞”模型，角部空洞四边外扩边框厚再裁剪。
3. 布条层：纵/横条按空洞边框截短或分段。
4. 边框层：`FrameSplitter` 按受力方向拆分，主边按净宽裁切、被包边按边框外扩裁切，绘图与下料表共用。
5. 轮廓层：有向边界段拼接生成板件外轮廓与净空轮廓，角部空洞可正确闭合。
6. 自测：`autocad-plugin/test/GridTest` 直接对 DXF 验证识别与边框拆分。

## 8. 验收用例

- 纯凸：1000 x 1000 板 + 顶部 200 x 200 凸出。
- 纯凹：1850 x 1240 + 两个顶部 190 深缺口（现有用例）。
- 凹凸混合：顶部凹口 + 侧边凸出。
- 角部：右下角 300 x 250 缺口（`三个图形.dxf` 图 3 形状）。
